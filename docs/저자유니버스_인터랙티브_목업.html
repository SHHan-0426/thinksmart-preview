출판사 저자 목록을 넘어, 저자 한 사람 = 하나의 작은 세계로. 사람·책·마을학교·인스타를 하나의 동선으로 잇고, 저자마다 책의 세계에서 끌어낸 시그니처 인터랙션을 홈페이지와 연동합니다. 실제 데이터로 만든 세 저자 — 강현구·홍재기·이관로 — 로 개념을 증명합니다.

핵심 개념

모든 저자 페이지는 홈으로 흐르고, 홈은 저자로 되돌아온다

기존 사이트의 강점(4축 크로스링크)을 유지하되, 저자 페이지를 '정보 나열'에서 '몰입 경험'으로 끌어올립니다. 네 개의 축이 서로를 참조하며 순환합니다.

01 · 사람

저자 유니버스

저자별 테마 컬러·모션·시그니처 인터랙션. 약력·대표작·SNS를 한 화면에.

02 · 책

책 → 저자 왕복

책 상세에서 저자로, 저자에서 전작으로. 알라딘·교보·예스24 실구매 링크 연동.

03 · 마을학교

배움으로 연결

저자가 참여한 낭독학교·사춘기살롱 등으로 오프라인 만남까지.

04 · 인스타

지금 이 순간

저자 관련 게시물을 자동 매칭해 살아있는 근황을 홈·저자 페이지에 노출.

오프라인으로 연결

저자 → 마을학교(낭독·사춘기살롱) → 신청. 미보유 저자는 신규 프로그램으로 발굴.

구축 로드맵

기존 정적 사이트 위에 4주로 얹는다

현재 Vanilla HTML/CSS/JS · Netlify 자동배포 구조를 그대로 활용. 빌드 도구 추가 없이 컴포넌트만 확장합니다.

1주차

저자 유니버스 프레임

저자별 테마 토큰(컬러·모션)·상세 페이지 리팩터. 세 저자 파일럿.

2주차

시그니처 인터랙션

질문 봇·공저 성좌·식물 성장 3종 구현. 접근성·음성 옵션 포함.

3주차

홈 연동·로테이션

'오늘의 저자' 슬롯, 버튼형 진입, 마을학교/인스타 자동 매칭 강화.

4주차

확산·QA·배포

A등급 30명으로 템플릿 확산, 크로스브라우저 QA, 대표 검수·오픈.

데이터 준비 · 선결 과제

세 저자 모두 photo·bio·insta 필드가 비어 있습니다(현재 이니셜 아바타 대체). 유니버스 몰입도를 위해 저자 사진·한 줄 소개·SNS 링크 수집이 1주차 병행 과제입니다. 책 표지는 알라딘 OpenAPI로 자동 보강 예정. 인스타 매칭은 이미 저자별 ig_post_ids로 연동되어 있어 즉시 활용 가능합니다.
